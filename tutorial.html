车机安装教程

图文步骤指引，手把手教你开启 ADB 并安装应用

1

打开工程模式

进入车机「设置」，选择「通用」，在页面右下角空白处连续点击 8 下

设置 → 通用 → 右下角点 8 下
2

点击加密项

进入工程模式后，在页面左下角找到「加密项」，点击进入

工程模式 → 点击「加密项」
3

输入密码

系统会显示产品序列号，将序列号后六位乘以 802018，取结果的后六位作为密码

密码 = 序列号后六位 × 802018 → 取结果后六位
4

点击 ADB 开关

输入密码后进入客制化页面，找到「ADB 开关」并点击

客制化页面 → 点击「ADB开关」
5

开启 ADB

进入 ADB 开关页面后，点击「打开」按钮开启 ADB 调试

点击「打开」→ ADB 已开启
6

有线连接并安装

使用 OTG + 公对公数据线有线连接车机，点击「连接」，然后切换到「安装」页面选择需要安装的软件

OTG + 公对公数据线 → 连接 → 安装
第六步：USB OTG 连接车机，点击「连接」
第七步：切换到「安装」，选择需要安装的软件
★

X70L 专用教程

X70L 车型仅需 U 盘即可打开 ADB，无需 OTG 数据线有线连接。将 U 盘插入车机 USB 接口，即可打开 ADB 模式。

U 盘内的文件请联系管理员获取，扫码下方二维码联系管理员。

扫码联系管理员获取 U 盘文件

电脑远程安装

如果你不方便自己操作车机安装，可以联系管理员通过远程方式帮你安装。

步骤：

1. 在电脑上下载安装 ToDesk 远程软件

2. 打开 ToDesk，将你的设备代码和密码发给管理员

3. 管理员远程连接后帮你完成安装

下载 ToDesk

支持 Windows / macOS / Linux，个人版免费使用

安装好 ToDesk 后，扫码联系管理员，把你的 ToDesk 设备代码和密码发给管理员即可。

扫码联系管理员进行远程安装

所需工具

安装前请准备好以下工具，手机安装和电脑安装所需工具不同

手机安装：安卓手机 + OTG线（二选一） + 双公头USB线（0.5-1米）
电脑安装：Windows笔记本 + 双公头USB线
U盘（X70L车型专用，仅需U盘即可打开ADB）
